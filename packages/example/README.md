# Example app

A small Vite + React app that consumes the built `@healthnz/pattern-library` and `@healthnz/pattern-library-themes` packages, for checking components in a real app context.

Build both packages first from the repo root with `yarn build`, then:

```bash
# Start the dev server on http://localhost:3000
$ yarn start
# Production build to ./build
$ yarn build
# Serve the production build locally
$ yarn preview
```
