### Description
A semantic button that looks like a link. Selecting a TextLinkButton will complete an action just like a Button would. Compared to a standard text Link that will only reposition you somewhere else by changing the URL.

### When to use it
Use a TextLinkButton when you need to confirm an action, but need the styling of a Link.

### When not to use it
Do not use a TextLinkButton within a body of text. Use standard text link instead.
