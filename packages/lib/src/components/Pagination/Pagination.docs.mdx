### Description
A Navigation component that can divide a long list into multiple pages, and only load one page at a time.

### When to use it
Use Pagination if content will take a long to load, or to help users browse information by navigation through pages.

### When not to use it
Do not use pagination as a replacement for an applications primary navigation.
