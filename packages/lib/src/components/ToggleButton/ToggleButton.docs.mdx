### Description
A control that has two mutually-exclusive states.

### When to use it
Use a ToggleButton to allow user to select one of two options.

### When not to use it
Do not use ToggleButton if you require a user to select multiple options or there are more than 2 options.

### Accessibility
Uses <a href="https://www.w3.org/TR/wai-aria-practices-1.2/examples/radio/radio.html">roving tabindex</a> to manage focus movement among items.
