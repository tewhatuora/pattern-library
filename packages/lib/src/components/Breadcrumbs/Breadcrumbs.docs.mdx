### Description

Breadcrumb navigation allows users to visualise their location on a website.

Underline, font weight, and whether the links should display visited link styles can be applied on a per-link basis, or font weight can be applied for all links with the `boldLinks` or `boldText` props and the visted styles can be disabled with the `noVisited` prop.

### When to use it

Use Breadcrumbs on all pages deeper than the homepage or landing pages.

### When not to use it

Do not use a Breadcrumb on single page sites or on a dashboard
