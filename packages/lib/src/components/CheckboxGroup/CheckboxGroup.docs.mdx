### Description
CheckboxGroup is a component made up of a list of Checkboxes with labels

### When to use it
Use CheckboxGroup to enable users to pick multiple options from a group during a form submission.

### When not to use it
Do not use CheckboxGroup if you require users to select only one option from a list.

### Accessibility
Adheres to the <a href="https://www.w3.org/TR/wai-aria-practices-1.2/#checkbox">tri-state Checkbox WAI-ARIA design pattern</a>.
