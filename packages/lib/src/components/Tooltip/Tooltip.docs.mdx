### Description
Tooltips are small popups that contain a short written explanation. Tooltips are triggered on hover on desktop, and on tap on mobile.

### When to use it
Use Tooltips to provide short explanations that do not need to be always visible. Tooltip are generally triggered from an Information icon, but can be trigger by a text link.

### When not to use it
Tooltips should not be used to highlight critical information, or when a user needs to be linked to another page.
For messages that need to be persistent, use a notice.
For longer messages, use a paragraph of text.
