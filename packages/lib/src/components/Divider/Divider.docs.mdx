### Description
Dividers bring clarity to a layout by grouping and dividing content in close proximity. They can also be used to establish hierarchy and make content easier to scan.

### When to use it
Use Dividers to separate content. A Divider should be followed by a new heading.

### When not to use it
Do not use dividers to break up paragraphs that flow on from each other

### Accessibility
Adheres to the <a href="https://www.w3.org/TR/wai-aria-1.2/#separator">`separator` role requirements</a>.
