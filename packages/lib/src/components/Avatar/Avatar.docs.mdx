### Description
A letter avatar is a graphical representation of a user's initials typically the first letter of their name.

### When to use it
Letter avatars can be used as a design element to add a personalized touch to a website or application, particularly in cases where the users' identity is important to the functionality or branding of the platform.
Use it when it is useful for the user to know they are logged in or if there are possibly mutliple accounts.

### When not to use it
Avatars should not be used when you need to show more than a single character of text.
Avatars should not be used to represent anything other than a user.
