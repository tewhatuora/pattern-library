### Description
RadioGroup is a component made up of a list of Radio buttons with labels.

### When to use it
Use RadioGroup to enable users to pick exactly one option from a group during a form submission

### When not to use it
Do not use RadioGroup if you require users to select more than one option from a list.

Do not use RadioGroup if you have a large number of options or the descriptions are lengthy.
