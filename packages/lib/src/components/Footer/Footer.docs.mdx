## Description

The Footer is a foundational component. It provides added information and navigation options at the bottom of all main mobile and desktop pages

## When to use it

The Footer must be placed at the bottom of all screens.

## When not to use it

Do not place a Footer over the background element of a Modal Dialog.

## API Reference

### Root

Contains all the parts of the footer.

The direct children for the `Footer.Root` should be one to five:

- `Footer.List`

### List

Contains the footer's list items.

The direct children for the `Footer.List` should be:

- `Footer.ListItem`

### ListItem

The list item links for the footer.
