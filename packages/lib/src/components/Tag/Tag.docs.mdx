### Description
Tags for user-provided content. Tags are compact elements that can be used for categorising or markup

### When to use it
Use the Tag component to categorise and organise content. Tags can be persistent or dismissible.

### When not to use it
Do not use the Tag component for numerical counts. Use a badge instead.
