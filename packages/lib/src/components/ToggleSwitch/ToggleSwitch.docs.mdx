### Description
A control that has two mutually-exclusive states. Always has a default value.

### When to use it
Use a ToggleSwitch to switch between two states or on-off state. A ToggleSwitch will trigger a state change directly when you toggle it, while a CheckboxGroup will need to work in conjunction with a submit request.

### When not to use it
Do not use ToggleSwitch if you require a user to select multiple options or there are more than 2 options.
