### Description
Alerts are small informative, positive, cautionary or critical messages. These messages have a stronger visual treatment than Notices.

### When to use it
Use Alerts for persistent messages that have the option to be dismissible.
These message should inform or provide feedback to users

### When not to use it
Alerts should not be used as Error states for input fields.

For messages that require less visual treatment, use a Notice
