### Description
An input field for searching.
On search, leads to search results page.
System default list picker can be used for styling.

### When to use it
Use InputSearch anytime you require users to find a single result.
NOTE: Does not replace the search functionality of the header component.

### When not to use it
Do not use InputSearch if you require users to select from a small list of options. Consider using a RadioGroup or InputDropdown instead.
