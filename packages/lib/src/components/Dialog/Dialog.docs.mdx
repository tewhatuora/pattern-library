### Description
A Dialog is a full screen overlay that prompts users to take or complete an action. The Dialog component must be placed on the Background Component

### When to use it
Use Dialogs to display information or allow users to interact with the application without jumping to a new page. Dialog's should display information that is related to the current user flow.

### When not to use it
Do not use Dialogs for complex interactions or to display nonessential information that is not related to the current user flow.

### Accessibility
Adheres to the <a href="https://www.w3.org/TR/wai-aria-practices-1.2/#dialog_modals">Dialog WAI-ARIA design pattern</a>.
