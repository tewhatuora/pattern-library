### Description
A Notice is an inline message and can be informative, positive or critical. These messages have less urgency than Alert messages.

### When to use it
Use Notices for persistent messages. These message should inform or provide feedback to users.

### When not to use it
A Notice should not be used as an Error state for input fields.
For messages that require more visual treatment, use an Alert.
