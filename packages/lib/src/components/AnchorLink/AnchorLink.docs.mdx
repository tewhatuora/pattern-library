### Description
An AnchorLink links to a specified anchor point within the same page.

### When to use it
Use AnchorLinks to structure complex pages to help users quickly navigate the content.

### When not to use it
"Do not AnchorLinks for every paragraph on the page.
AnchorLinks should correspond to a similar Heading or Subheading within the page.
Avoid using AnchorLinks for pages with very little content and don't scroll."
