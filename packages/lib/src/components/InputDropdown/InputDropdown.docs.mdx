### Description
An input component that allows users to select a single option from a list. The system default list picker is recommended for styling.

### When to use it
Use InputDropdown to enable users to pick a single option from a list during a form submission

### When not to use it
Do not use InputDropdown if you require users to select more than one option from a list.
