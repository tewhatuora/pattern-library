## Install

```bash
npm install --save moh-design-system
```

## Set Up

At the root of your application, import the required theme and the [`ThemeProvider`](/components/ThemeProvider) component.

```tsx
import myCovidRecord from 'moh-design-system/themes/myCovidRecord';
import { ThemeProvider, Text } from 'moh-design-system';
// ...etc.
```

Finally, wrap the root of your application with the `ThemeProvider` component, providing the imported theme via the `theme` prop.

```tsx
import myCovidRecord from 'moh-design-system/themes/myCovidRecord';
import { ThemeProvider, Text } from 'moh-design-system';

export default () => (
  <ThemeProvider theme={myCovidRecord}>
    <Text>Hello World</Text>
  </ThemeProvider>
);
```
