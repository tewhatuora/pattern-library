# Installation

Two NPM packages compose the pattern library. The design system component library named `@healthnz/pattern-library`, and a themes package, `@healthnz/pattern-library-themes`. The themes package is a peer dependency of the library, so install both.

We assume you've already set up `react` and `react-dom`. Otherwise, you'll get a warning at installation.

## Install packages

To install, open a terminal at the root of your project workspace and run the following command:

<Source
  language="bash"
  dark
  code={`$ yarn add @healthnz/pattern-library @healthnz/pattern-library-themes\n$ # or using NPM\n$ npm install @healthnz/pattern-library @healthnz/pattern-library-themes`}
/>


## Include fonts

Each theme uses Google Fonts: "Poppins" for the Neutral theme and "Public Sans" for the Web Self-Service theme.

Include the relevant resources in your HTML:

<Source

## Import styles

The pattern library styles include a CSS bootstrap and the component styles, and the themes styles define each theme's values.

To import styles add the following import declaration to your root app:

CSS in JS

<Source
  language="js"
  dark
  filename="index.js"
  code={`import '@healthnz/pattern-library/styles';\nimport '@healthnz/pattern-library-themes/styles';`}
/>

## Configure your application

Below is an example of how to configure an application with a pre-constructed theme object:

<Source
  language="tsx"
  dark
  code={`import '@healthnz/pattern-library/styles';
import '@healthnz/pattern-library-themes/styles';\n
import { ThemeProvider } from '@healthnz/pattern-library';
import { neutral } from '@healthnz/pattern-library-themes';
\n
<ThemeProvider theme={neutral}>
  <App />
</ThemeProvider>`}
/>

Instead of harcoding the foundation values in the pattern library, we choose to implement a theming system allowing applications to supply their core values to the library.

The theming system introduced a concept of theme object. To configure, you'll need to build your own theme object or import a pre-constructed one. The theme object will be used to render the foundation variables and define a theme provider at the root of your application.

### Start creating components

You're all set! You can start creating your application with the pattern library:

<Source
  language="tsx"
  dark
  code={`import { Container, Text, Button } from '@healthnz/pattern-library';\n
export const App = () => (
  <Container>
    <Text>Hello World!</Text>
    <Button variant="primary">Primary button</Button>
  </Container>
);`}
/>
