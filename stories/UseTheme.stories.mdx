# Theming

Instead of harcoding the foundation values in Anatomic, we choose to implement a theming system allowing applications to supply their core values to Anatomic.

The theming system introduced a concept of theme object. To configure Anatomic, you'll need to build your own theme object or import a pre-constructed one from Anatomic. The theme object will be used to render the foundation variables and define a theme provider at the root of your application.

<Source
  language="tsx"
  dark
  code={`import '@te-whatu-ora/anatomic/styles';\n
import { ThemeProvider } from '@te-whatu-ora/anatomic';
import { neutral } from '@te-whatu-ora/anatomic-themes';\n
<ThemeProvider theme={neutral}>
  <App />
</ThemeProvider>`}
/>

## useTheme hook

The `useTheme` hook provides access to the theme variables that are available on the theme passed to `ThemeProvider`.

<Source
  language="tsx"
  dark
  code={`import { useTheme } from '@te-whatu-ora/anatomic';\n// ...\nconst { tokens } = useTheme();`}
/>


## Custom components

Using the theme variables allows custom components to be created, with consistent theming.

<Source
  language="tsx"
  dark
  code={`const MyComponent = () => {
  const { tokens } = useTheme();\n
  return (
    <div style={{
      backgroundColor: tokens.color.annotation75,
      marginBottom: tokens.space.large.tablet
    }}>
      My component
    </div>
  );
};
`}
/>
